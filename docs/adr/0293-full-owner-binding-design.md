## Context and constraints

The corrected artificial entry/adapter passed its targeted checks. Native profile,
admission, external gate and operator bindings still describe a consumed single-
forward completed probe. Reusing their labels would not bind the full original
eight-outcome/two-arc fixture. This design turns the existing map into one concrete
binding contract; it adds no controller and opens no scientific free variable.

## Options considered

- Retag the successful artificial slice or consumed completed profile: rejected;
  neither supplies native full-owner authority or fresh admission.
- Build another generic framework or repeat unchanged campaigns: rejected; the
  missing work is a finite set of field/command bindings.
- Reuse existing primitives and specify only the changed bindings: selected.

## Decision and rationale

The frozen binding contract, detailed field map and two design templates are
retained in the evidence archive. Every changed runtime field/command has a prior
source pin/anchor, new value or deterministic derivation, and required check.

| Piece | Treatment |
| --- | --- |
| call-once / launch-once | Byte-identical reuse candidates; dynamic profile, existing cold clock and cleanup. |
| run-once / sandbox / preservation | Fixed namespace and factual label substitution only, verified byte-for-byte. |
| entry / adapter / admission | Three logic-changed active controls: exact full-owner scope and thin unchanged-runner delegation. |
| external dispatch gate | Separately pinned changed binding, outside eight active controls. |
| prepare / review / invoke operators | Exact profile, decision, contract, pin and original-clock bindings. |
| profile / decision | New fixed future bytes; current templates are NOT_ADMITTED design objects. |

Native delegation uses unchanged run(raw,packetdir,started_s=original,
inherited_group=True) from the isolated PID=PGID=SID entry. Native producer and
audit commands remain the original private sys.executable -m
space_nav._owner_endpoint_run --worker produce|audit source repr(start) repr(cutoff).
Native mode accepts no replacement commands. Artificial substitution may affect
only produce in an explicitly artificial API; the original guarded auditor stays
independent. No completed ten-marker assumptions are transferred.

The original three modules already belong to the retained 53-source cohort.
Keep 10 native identities, 11 resources, 25 ledgers, 86 historical members and the
existing environment/image. All 15 previously selected control/profile/operator
members were checked; the old result JSON lists 13, while its archived complete
manifest pins the other two. No new source or resource cohort was introduced.

The runtime profile keeps its old exact keys with probe_input renamed fixture_input
and the original two-key fixture input. The nine-key decision remains distinct.
Design wrappers contain absent future stage/base/choice/pins/clock fields and
references; real admission must reject these. A separate deterministic <=64KiB
runtime mapping is generated from the fixed rules and frozen identities, then
pinned before candidate control constants: no self-hash cycle or design-as-proof.

Preserve independent 0/1000 s literals, eight ordered outcomes/two arcs, original
own-literal oracle/schema/settings/metadata, 3 factory / 2 analytic-attempt /
8 visitor / 100000 precharged-callback ceilings, and original dimensional gates.
Reverse initialization is independent, not a carry test. Native function-count
telemetry stays separate. Unknown partial counts remain UNKNOWN.

Start any future actual preflight clock before the first namespace write or mount.
Preparation, read-only resource observation, independent actual review, admission
and consumption must all occur within strict <600s. The packet retains inclusive
60s with 45s producer / <=10s audit by55s / 5s finalization; 65s is failure-only.
Keep all original byte partitions, whole-group cleanup, preservation/detach and
clock observation after the last file+directory fsync. Retained admission is not
fresh authority. No actual namespace was created or image mounted in this design.
